# AgriSense Dashboards

Role-based dashboards for the AgriSense platform, built with React, Vite, and Tailwind CSS. The landing page lets you enter one of three portals.

## Supplier portal (`/supplier`)

- **Dashboard** – KPIs, product supply mix, supply volume monitoring, order activity
- **Orders** – buyer orders with statuses and filters
- **Inventory** – stock levels, low-stock alerts, product catalog
- **Deliveries** – shipment schedule and statuses
- **Analytics** – revenue/volume trends, top products, buyer concentration
- **Buyers** – buyer relationships and order history
- **Settings** – supplier profile and business information
- **Help & Support** – FAQ and contact

## Government portal (`/gov`)

- **Dashboard** – national KPIs, regional production share, production monitoring, subsidy activity
- **Regions** – production and food security by province
- **Subsidies** – support programs, budgets, and disbursement
- **Registry** – licensed suppliers, buyers, and processors
- **Reports** – published assessments and program reports

## NGO portal (`/ngo`)

- **Dashboard** – program KPIs, focus mix, beneficiaries reached, distribution activity
- **Programs** – field programs and budget utilization
- **Beneficiaries** – cooperatives and farmer groups supported
- **Distributions** – seed/tool/equipment distributions
- **Funding** – donor commitments and utilization

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:5173.
